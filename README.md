# OutfitOrbit — Digital Wardrobe

A responsive, front-end digital wardrobe project made with HTML, CSS, Tailwind CSS and JavaScript.

## Run it
1. Extract `OutfitOrbit.zip`.
2. Open the `OutfitOrbit` folder in VS Code.
3. Start `index.html` using the Live Server extension (recommended), or open it directly in a browser.
4. Internet is required for Tailwind's CDN, Google Fonts and the demo Unsplash images.

## Features
- Add clothes with name, category, optional image URL and note.
- Filter by category and search the wardrobe.
- Select clothing items in the Outfit Studio.
- Generate a random outfit.
- Save outfits, favorite them, load them back into the studio, or delete them.
- Data is saved in browser LocalStorage.
- Responsive layout for mobile and desktop.

## Files
- `index.html`: page structure and Tailwind CDN
- `style.css`: custom styling and responsive layout
- `script.js`: app logic and LocalStorage

## Important note
This is a front-end demo. LocalStorage data is saved only in the current browser on the current device; it is not synced between users or devices.
